# Contributing to Royal Cleaning & Sterilization

We welcome contributions from the community! This document outlines how to contribute to this project.

## Getting Started

1. Fork the repository
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR-USERNAME/Royal-Cleaning-Sterilization.git
   cd Royal-Cleaning-Sterilization
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Create a new branch for your feature:
   ```bash
   git checkout -b feature/your-feature-name
   ```

## Development

### Prerequisites
- Node.js 18+
- npm or yarn

### Running Locally
```bash
npm run dev
```

### Building
```bash
npm run build
```

### Preview
```bash
npm run preview
```

## Making Changes

1. Make your changes
2. Test your changes locally
3. Commit with clear messages:
   ```bash
   git commit -m "feat: add feature description"
   ```
4. Push to your fork
5. Create a Pull Request with a clear description

## Code Style

- Use TypeScript for type safety
- Follow existing code patterns
- Use Tailwind CSS for styling
- Add comments for complex logic

## Pull Request Process

1. Update documentation if needed
2. Ensure the application builds successfully
3. Request review from maintainers
4. Address review feedback

## Reporting Issues

Use GitHub Issues to report bugs or suggest features. Include:
- Clear description
- Steps to reproduce (for bugs)
- Expected vs actual behavior
- Environment details
