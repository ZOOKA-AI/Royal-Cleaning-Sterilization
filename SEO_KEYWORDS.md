## ✅ KEYWORD USAGE BEST PRACTICES

### On-Page SEO:
- Title Tag: Primary keyword + location (50-60 chars)
- Meta Description: Primary + secondary keywords (150-160 chars)
- H1: Primary keyword (only one H1 per page)
- H2-H3: Secondary and LSI keywords
- First 100 words: Include primary keyword naturally
- Image ALT text: Descriptive with keywords
- URL: Include primary keyword (kebab-case)

### Content Guidelines:
- Keyword density: 1-2% (natural usage)
- Use variations and LSI keywords
- Include bilingual keywords (AR + EN)
- Answer user questions directly
- Use location keywords throughout
- Include semantic variations

### Avoid:
- Keyword stuffing
- Unnatural keyword usage
- Exact match anchor text overuse
- Irrelevant keyword targeting
- Duplicate content across pages
